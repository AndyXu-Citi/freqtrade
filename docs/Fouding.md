# 跨交易所资金费率套利系统需求说明书

**版本：** V5.2
**更新日期：** 2026-01-16

---

## 一、项目概述

### 1.1 项目目标

开发一个自动化交易系统，遍历多个交易所的多个币种，实时计算所有交易所对之间的资金费率差异，按费率差排序优先处理最优机会，自动执行套利交易，并根据不同策略执行不同的监控逻辑。

### 1.2 核心策略逻辑

| 步骤 | 判断条件 | 结果 |
|------|----------|------|
| 1 | 当前持仓数是否 ≥ 最大并发持仓数？ | 是 → 等待释放；否 → 进入步骤2 |
| 2 | 当前币种是否有持仓？ | 是 → 跳过该币种；否 → 进入步骤3 |
| 3 | 费率差 > 费率阈值？ | 否 → 继续下一个交易所对；是 → 进入步骤4 |
| 4 | 基差方向与费率方向一致？ | 是 → 进入步骤5；否 → 进入步骤6 |
| 5 | 基差套利收益 > 基差套利收益阈值？ | 是 → 执行基差套利；否 → 继续下一个 |
| 6 | 快进快出收益 > 快进快出收益阈值？ | 是 → 执行快进快出；否 → 继续下一个 |

### 1.3 策略对比

| 策略 | 持仓时间 | 监控要求 | 风险等级 | 利润来源 |
|------|----------|----------|----------|----------|
| 快进快出 | 30秒 | 无需持续监控 | 极低 | 费率差 |
| 基差套利 | 几天-几周 | 需要持续监控 | 中等 | 费率差 + 基差收敛 |

## 二、核心概念与公式

### 2.1 基本定义

| 概念 | 定义 | 计算方式 |
|------|------|----------|
| 资金费率差 | 两个交易所的资金费率差值（绝对值） | 费率差 = \|费率_A - 费率_B\| |
| 滑点成本 | 开平仓时的预期滑点损耗 | 默认 0.2% |
| 手续费 | 双边开平总手续费 | 默认 0.1% |
| 基差率 | 两个平台合约价格的差异百分比 | 基差率 = (做空价 - 做多价) / 做多价 |
| 保证金比率 | 各交易所合约仓位的保证金比率 | 保证金比率 = 占用保证金 / 总资产 × 100% |

### 2.2 策略公式

| 策略 | 收益计算 | 判断条件 |
|------|----------|----------|
| 快进快出 | 快进快出收益 = 费率差 - 滑点成本 - 手续费 | 快进快出收益 > 快进快出收益阈值 |
| 基差套利 | 基差套利收益 = 费率差 + 基差率 - 滑点成本 - 手续费 | 费率差 > 费率阈值 AND 做空价 > 做多价 AND 基差套利收益 > 基差套利收益阈值 |

### 4.4 保证金比率监控说明

| 监控项 | 说明 |
|--------|------|
| 监控对象 | 该币种持仓涉及的所有交易所合约账户 |
| 计算方式 | 保证金比率 = 该币种占用保证金 / 该交易所总资产 × 100% |
| 触发条件 | 任一平台保证金比率 > 保证金阈值 |
| 处理方式 | 立即平仓该币种所有持仓 |

### 4.5 两策略监控对比

| 监控项 | 快进快出 | 基差套利 |
|--------|----------|----------|
| 是否需要持续监控 | 否 | 是 |
| 持仓时长 | 约30秒 | 几天-几周 |
| 保证金比率监控 | 不需要（持仓时间太短） | 需要（第一步检查） |
| 费率反转监控 | 不需要 | 需要 |
| 基差反向监控 | 不需要 | 需要 |
| 止盈监控 | 不需要 | 需要 |
| 止损监控 | 不需要 | 需要 |
| 超时监控 | 不需要 | 需要 |
| 结算后自动平仓 | 是 | 否 |
| 监控间隔 | 无 | 30秒 |

### 5.2 分批下单参数说明

| 参数 | 说明 |
|------|------|
| 订单类型 | 市价单（不担心单边成交问题） |
| 总金额 | 根据仓位占比计算的总投资金额 |
| 批次数 | 总金额分多少批下单 |
| 批次间隔 | 每批下单之间的等待时间 |
| 订单方式 | 双边同时下市价单 |

### 5.3 分批下单参数配置

| 参数 | 默认值 | 说明 | 范围 |
|------|--------|------|------|
| batch_count | 3批 | 分批次数 | 1 - 10批 |
| batch_interval | 30秒 | 批次间隔 | 10 - 60秒 |
| batch_retry_count | 3次 | 单批重试次数 | 1 - 5次 |
| batch_retry_interval | 5秒 | 重试间隔 | 3 - 10秒 |

### 6.2 持仓管理规则

| 规则项 | 说明 |
|--------|------|
| 全局并发限制 | 系统启动时首先检查，当前持仓数 ≥ 最大并发数则等待，不处理任何新机会 |
| 币种唯一性 | 同一币种只能有一个套利持仓（无论是快进快出还是基差套利） |
| 策略类型记录 | 开仓时记录该持仓的策略类型，供监控流程分发使用 |
| 快进快出 | 持仓时间极短（约30秒），自动平仓后持仓数-1 |
| 基差套利 | 持仓时间较长，监控触发平仓后持仓数-1 |
| 分批下单 | 分批下单过程中持仓数不变，全部完成后才增加持仓计数 |

### 6.3 持仓管理参数

| 参数 | 默认值 | 说明 | 范围 |
|------|--------|------|------|

## 八、快进快出策略

### 8.1 触发条件

| 条件 | 公式 | 说明 |
|------|------|------|
| 全局持仓数 < 最大并发 | — | 系统级限制 |
| 币种无持仓 | — | 同一币种不重复开仓 |
| 费率差 > 费率阈值 | 费率差 > fee_threshold | 第一步过滤 |
| 基差方向不一致 | 做空价 ≤ 做多价 | 基差与费率方向相反 |
| 快进快出收益 > 快进快出收益阈值 | 费率差 - 滑点成本 - 手续费 > quick_profit_threshold | 扣除所有成本后仍有利润 |

### 8.2 执行流程

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 等待 | 距离下次费率结算前10秒 |
| 2 | 分批下单 | 调用分批下单流程 |
| 3 | 记录 | 记录策略类型为"快进快出" |
| 4 | 进入监控 | 进入监控流程（统一入口） |

### 8.3 参数配置

| 参数 | 默认值 | 说明 | 范围 |
|------|--------|------|------|
| slippage | 0.2% | 滑点成本 | 0.1% - 0.5% |
| fee_rate | 0.1% | 双边开平总手续费 | 0.05% - 0.2% |
| fee_threshold | 0.15% | 费率阈值 | 0.1% - 0.5% |
| quick_profit_threshold | 0.05% | 快进快出收益阈值 | 0.02% - 0.2% |
| quick_advance_time | 10秒 | 结算前开仓时间 | 5 - 30秒 |
| quick_position_ratio | 5% | 单笔仓位占比 | 2% - 10% |
| batch_count | 3批 | 分批次数 | 1 - 10批 |
| batch_interval | 30秒 | 批次间隔 | 10 - 60秒 |

## 十三、公式汇总

| 公式 | 说明 |
|------|------|
| 费率差 = \|费率_A - 费率_B\| | 资金费率差 |
| 基差率 = (做空价 - 做多价) / 做多价 | 基差率 |
| 快进快出收益 = 费率差 - 滑点成本 - 手续费 | 快进快出实际收益 |
| 基差套利收益 = 费率差 + 基差率 - 滑点成本 - 手续费 | 基差套利实际收益 |
| 快进快出条件 = 快进快出收益 > quick_profit_threshold | 快进快出触发 |
| 基差套利条件 = 费率差 > fee_threshold AND 做空价 > 做多价 AND 基差套利收益 > basis_profit_threshold | 基差套利触发 |
| 保证金比率 = 占用保证金 / 交易所总资产 × 100% | 保证金比率计算 |
| 费率反转幅度 = 当前费率差 - 初始费率差 | 反转判断 |
| 基差收敛比例 = (初始基差 - 当前基差) / \|初始基差\| × 100% | 收敛判断 |
| 每批金额 = 总金额 / batch_count | 分批金额计算 |
